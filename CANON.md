# CANON.md — Точка входа для исполнителя

Назначение: этот файл — обязательная первая точка контакта для любого ИИ-исполнителя
(Claude Code, Claude в чате, любая другая модель), приступающего к работе над
проектами, связанными с системой знаний Foundation.

Это реализация решения по GS-00X (Knowledge Runtime).

## Протокол доступа

1. Исполнитель обязан прочитать этот файл ПЕРЕД тем как предлагать, изменять
   или реализовывать любое архитектурное решение, относящееся к Foundation.
2. Канон живёт по адресу этого репозитория: `github.com/LuckyBait/Foundation`.
   Актуальная версия — содержимое ветки `main`.
3. Версия канона фиксируется commit hash'ем. Любое решение, принятое
   исполнителем, должно ссылаться на канон вида:
   `Foundation @ commit <hash>`.
4. Если исполнитель не может прочитать актуальный commit (нет доступа
   к сети/репозиторию) — он обязан явно сообщить об этом человеку,
   а не действовать по памяти или по устаревшей локальной копии.
