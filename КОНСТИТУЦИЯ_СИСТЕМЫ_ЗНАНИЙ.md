# Конституция системы знаний v1.0

## Аксиомы
1. Процесс первичен.
2. У каждой архитектурной идеи один владелец.
3. Один этап — одна цель.
4. Анализ предшествует изменениям.
5. Контекст определяется этапом.
6. Архитектура уменьшает стоимость поиска информации.
7. Фундамент изменяется только отдельным архитектурным решением.
