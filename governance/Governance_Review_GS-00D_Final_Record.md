# Governance Review — GS-00D

## GS-00D — Formal Governance Review Ordering / Prioritization

Статус решения: ACCEPTED

Дата: 2026-08-09

### Основание

Process Check и анализ действующих Governance records установили, что Governance System определяет жизненный цикл отдельного Governance item:

Observation → Governance Review → Decision → Implementation → Verification

но не определяет формальный механизм выбора очередности нескольких одновременно ожидающих Governance Reviews.

### Проблема

При наличии нескольких observations исполнитель не должен самостоятельно выбирать следующий Review на основании субъективной оценки, кратчайшего маршрута, порядка появления идеи или истории текущего чата.

Особенно важны зависимости: одно Governance decision может быть необходимой предпосылкой для корректного рассмотрения другого.

### Решение

Governance Review принимает GS-00D.

Governance System должен иметь формализованный механизм определения очередности Governance Reviews.

При этом данный Review НЕ утверждает конкретный численный алгоритм или формулу приоритета. Сначала фиксируется сам принцип обязательной объективной очередности; конкретная реализация может быть определена отдельным Governance item только после появления достаточного практического основания.

### Обязательные свойства механизма

1. Зависимости между Governance items должны быть явно фиксируемыми.
2. Governance Review с невыполненными обязательными зависимостями не должен считаться допустимым следующим действием.
3. Очередность должна учитывать текущий этап и цель текущего процесса.
4. Приоритет не может определяться только субъективным предпочтением исполнителя.
5. Механизм должен иметь durable repository record, позволяющий восстановить причину выбора следующего Review без истории чата.
6. Сам механизм не должен нарушать неизменяемость Foundation v1.0.

### Ограничение решения

Не утверждается конкретный алгоритм сортировки, числовая priority-модель или автоматический scheduler. Это сознательно оставлено для будущего Governance Review, если практика покажет необходимость такого уровня формализации.

### Следующее допустимое действие

После принятия GS-00D необходимо выполнить Process Check и определить, есть ли уже достаточные данные для определения очередности существующих Governance items на основании зафиксированных зависимостей.

Если формальных зависимостей между существующими items пока недостаточно, сначала должен быть создан durable dependency map как evidence/operational record, а не субъективный список приоритетов.

Foundation v1.0 не изменяется.
